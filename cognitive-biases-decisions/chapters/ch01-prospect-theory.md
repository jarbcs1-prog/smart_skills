# Chapter 1: Prospect Theory

## Key concepts

- **Reference point:** outcomes evaluated as gains/losses relative to a reference, not final states.
- **Loss aversion:** losses weigh ~2x gains.
- **Risk preferences:** risk-averse for gains, risk-seeking for losses.
- **Framing:** gain vs. loss frame changes choice.
- **Probability weighting:** small probabilities overweighted, large underweighted.

## Heuristics

- Always identify the reference point before evaluating a choice.
- Reframe a loss as a gain (or vice versa) to test stability of preference.
- Check for loss-aversion-driven escalation (sunk cost).

## Application prompt

"What is the reference point? Is this framed as gain or loss? What changes if reframed?"
