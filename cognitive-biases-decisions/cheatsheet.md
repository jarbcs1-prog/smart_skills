# Cheatsheet — Cognitive Biases

| Bias | Quick test | Mitigation |
|------|-----------|------------|
| Loss aversion | Losses weigh 2x gains | Reframe; widen reference |
| Availability | Vivid/recent overweighted | Use base rates |
| Anchoring | First number sticks | Generate own anchor |
| Overconfidence | "I'm sure" | Seek disconfirming |
| Confirmation | Only confirming sought | Red-team |
| Sunk cost | "Already invested" | Ignore past costs |
| Status quo | "Keep as is" | Cost of inaction |
| Framing | Wording changes choice | Restate both frames |
