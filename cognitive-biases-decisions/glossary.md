# Glossary — Cognitive Biases

- **Prospect theory:** evaluation relative to reference point; loss aversion.
- **Loss aversion:** losses weigh ~2x gains.
- **Framing:** presentation changes choice.
- **Availability:** ease of recall.
- **Representativeness:** similarity to prototype; base-rate neglect.
- **Anchoring:** first number sticks.
- **Overconfidence:** overestimation of knowledge/ability.
- **Confirmation bias:** seek confirming evidence.
- **Hindsight bias:** retroactive "I knew it."
- **Sunk cost:** past investment drives continuation.
- **Status quo bias:** prefer current state.
- **Reference point:** baseline for gain/loss evaluation.
- **Probability weighting:** small probs overweighted.
