# Patterns — Cognitive Biases

## Techniques
1. **Reference-point identification:** find the baseline before evaluating.
2. **Reframing test:** restate as gain/loss; check preference stability.
3. **Base-rate check:** what is the prior probability?
4. **Disconfirming search:** what would prove this wrong?
5. **Pre-mortem:** assume failure; list causes.
6. **Debiasing by widening:** expand the reference point/time horizon.

## Anti-patterns
- Treating heuristics as always harmful.
- Overcorrecting into paralysis.
- Ignoring reference dependence.
- Confusing outcome quality with decision quality.
