# Patterns — Dark Psychology Defenses

## Techniques
1. **Tactic naming:** identify and name the manipulation.
2. **Documentation:** record events; reduce ambiguity.
3. **Boundary-setting:** clear, consistent, unexplained.
4. **External perspective:** maintain outside relationships.
5. **Grey rock:** reduce engagement/reward.
6. **Safety planning:** for coercive control situations.

## Anti-patterns
- Using defensively-learned tactics offensively.
- Paranoia: not all difficulty is manipulation.
- Arguing with the manipulation.
- Isolating oneself further.
