# HITIDR Route Table — signals to analytical capabilities

One page. Use this to route a live interaction to the right analytical skill.

| When the signal is | Use this skill | Why |
|---|---|---|
| Rapid cascade of claims, deadlines, threats | `cognitive-biases-decisions` | Cognitive load exploitation (perceptual overload); slow down, isolate each claim |
| Gaslighting, DARVO, coercive control, love bombing | `dark-psychology-defenses` | Three-classifications (observed behavior/potential tactic/threat assessment) |
| Unverified authority, fabricated procedure, Kafkaesque bureaucracy | `kafka-metamorphosis-absurdity` | Detection questions (does it exist? is it documented? can it be confirmed?) |
| Value claims, incentives, power dynamics | `nietzsche-beyond-good-and-evil` | Genealogy: origin, interests served, evidence, interpretation |
| Projection, dependency, role manipulation | `psychoanalysis-structures` | Interaction dynamics only — never diagnosis of a real person |
| Fraudster objective, adversarial positioning | `strategic-red-team` | What would the fraudster achieve? (identity, credentials, money, data, access) |
| Authority, deception, terrain analysis | `sun-tzu-strategy` | Deception analysis (never use deception against the other party) |
| How to actually respond in a live call | `sales-negotiation`, `outbound-cold-calling-voice-agent` | Response procedures, call flows, compliance |
| Data analysis, anomaly detection, classification | `ml-python-stats-linearalgebra` | Analytical infrastructure, not real-time conversational layer |

Rule: HITIDR routes; it does not replace. Each cell names the skill the routing
agent must invoke. The routing decision is a hypothesis, not a verdict.
