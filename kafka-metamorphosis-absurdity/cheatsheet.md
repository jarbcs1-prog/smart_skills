# Cheatsheet — Kafka Absurdity

| Symptom | Kafkaesque diagnosis |
|---------|----------------------|
| Infinite loops in process | Bureaucratic labyrinth |
| Can't get X without X | Catch-22 |
| User feels blamed, no charge named | Guilt without crime |
| No human accountable | Unreachable authority |
| Care turns to resentment | Empathy half-life |
| Identity = single function | Role collapse |
