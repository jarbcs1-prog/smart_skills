# Chapter 2: Python for Data

## Key concepts

- **NumPy:** ndarray, vectorized ops, broadcasting, reshape, indexing.
- **Pandas:** DataFrame, Series, groupby, merge, pivot, missing data handling.
- **scikit-learn:** fit/predict/transform API, pipelines, GridSearchCV.
- **Visualization:** matplotlib, seaborn, plotly.
- **Performance:** vectorize, avoid loops, use appropriate dtypes, profile.

## Operational heuristics

- Prefer vectorized NumPy/Pandas over Python loops.
- Use pipelines to prevent leakage.
- Handle missing data explicitly (impute or drop).
- Type hints + docstrings for maintainability.
