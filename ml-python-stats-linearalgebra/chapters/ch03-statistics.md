# Chapter 3: Statistics

## Key concepts

- **Descriptive:** mean, median, std, variance, quantiles, correlation.
- **Inference:** hypothesis tests, p-values, confidence intervals, effect sizes.
- **Tests:** t-test, chi-square, ANOVA, Mann-Whitney, Wilcoxon, Pearson/Spearman.
- **Regression:** linear, logistic, assumptions, diagnostics (residuals, VIF, Cook's D).
- **Bayesian:** priors, likelihood, posterior; credible intervals.
- **Pitfalls:** p-hacking, multiple comparisons, confusing significance with importance.

## Operational heuristics

- Report effect size + CI, not just p-value.
- Check assumptions before choosing a test.
- Correct for multiple comparisons (Bonferroni, FDR).
- Distinguish statistical from practical significance.

## Application prompt

"Which test applies? What are the assumptions? What's the effect size?"
