# Glossary — ML/Python/Stats/LA

- **Bias-variance tradeoff:** underfit vs overfit.
- **Regularization:** L1/L2 penalty to reduce overfitting.
- **Cross-validation:** k-fold evaluation.
- **Feature engineering:** creating informative inputs.
- **Ensemble:** combining models (bagging/boosting/stacking).
- **NumPy ndarray:** N-dimensional array.
- **Pandas DataFrame:** tabular data structure.
- **scikit-learn:** ML library with fit/predict/transform API.
- **p-value:** probability of data given null.
- **Effect size:** magnitude of difference.
- **Confidence interval:** range for parameter.
- **PCA:** principal component analysis.
- **SVD:** singular value decomposition.
- **Eigenvalue/eigenvector:** matrix decomposition.
- **Norm:** vector/matrix magnitude (L1/L2/Frobenius).
- **Cosine similarity:** angle between vectors.
