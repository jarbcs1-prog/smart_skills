# Technique Index — Choosing the Right Approach

Load the technique that matches **who you are calling and why**, not the one that happens to be top of the list.

> **Before every call, read `live-call-quality-rules.md`.** Those six rules apply regardless of technique. Most bad calls fail on those, not on technique choice.

---

## Call type → technique

| Situation | Load | Not this |
|-----------|------|----------|
| Never heard of us, no prior contact | `technique-01-research-survey.md` | Technique 02 — they have no journey to mirror |
| Already saw a demo, calling back | `technique-02-customer-journey-mirror.md` | Technique 01 — they'll hear the survey framing as evasive |
| Dormant lead, past customer or win-back | `technique-03-revive-and-enrichment.md` | Technique 01 — assumes no history |
| Genuine survey/research/investigation | `technique-04-survey-and-inquiry.md` | Technique 01 — a pitch inside a survey destroys trust |
| Called and asked "what's this about?" | `technique-01` open + `outbound-compliance.md` | Anything with a pitch in the first line |
| "Not interested" | Exit cleanly, log, suppress if explicit | Any technique — a "no" is not an obstacle to overcome |
| Mid-call, you realize it's wrong type | Handover language in `persona-and-pitch-design.md` | Pressing on |
