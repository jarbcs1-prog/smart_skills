## Contract and neutrality (added 2026-11-09)
All skills in this corpus are now wired to the Skill Interface Contract (CONTRACT.md): SKILL.md is the router + hard gates + narrowest executable procedure; domain depth lives in  references/ or chapters/ and is loaded only on demand via explicit MANDATORY triggers. The skills are model-agnostic and context-agnostic: they can be invoked by any compatible model backend (the normalization layer lives in adapters/) and applied in any interaction context (voice, chat, email, async, audit, training), with the same hard gates and the same safety behavior. The voice AI cold-calling skill was restructured to express its voice levers as context adapter clauses.
