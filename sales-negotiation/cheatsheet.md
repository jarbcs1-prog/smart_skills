# Cheatsheet — Sales & Negotiation

| Situation | Move |
|-----------|------|
| First contact | Build rapport; positive first impression |
| Discovery | SPIN questions; active listening |
| Qualification | Controllable, liquid, interested, decision-maker |
| Price objection | Acknowledge, clarify, respond with value |
| Negotiation | Anchor; handle "do better?" with value |
| Closing | Ask for business; trial close |
| Silence | Scheduled follow-up |
| Complex deal | Escalate to specialist |
